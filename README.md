# Turkey Escape

A tiny first-person stealth game: sneak the turkey out of the house before Thanksgiving dinner without waking anyone.

Static site, no build step. Deploy this folder to Vercel as-is (or open `index.html` through any web server).

- Keyboard: ↑ / W to walk (hold to run, but it's loud), ← → to dodge, P to pause, M for sound.
- Phone / tablet (landscape): ◀ ▶ buttons to dodge, WALK button (tap to tiptoe, hold to run).
- Testing shortcuts on the title screen: 1–4 jump to a chapter, 0 shows the ending.
